# homebrew-tap

Homebrew formulae for eetu's tools.

| formula | what it is |
| --- | --- |
| `luoto` | dev sandboxes that contain supply-chain attacks ([eetu/luoto](https://github.com/eetu/luoto)); macOS and Linux |

```sh
brew install eetu/tap/luoto
```

Installing by full name trusts that formula only, not the whole tap; `brew upgrade` keeps it
current. Each formula is written by its project's release workflow, so changes belong there
([luoto's template](https://github.com/eetu/luoto/tree/main/packaging/homebrew)).
